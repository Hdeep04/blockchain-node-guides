## 2. ICSとは何か

ICS（Identified Community Staker）は、Lido CSM上で「個人の独立したステーカーである」ことを証明した運用者に与えられる、優遇されたオペレータータイプです。

```
Default（無認証）: APR最大4.27%、Bond 1.3〜2.4 ETH
ICS（認証済み）  : APR最大5.73%、Bond 1.3〜1.5 ETH
```

利回りが高くなるだけでなく、必要なボンド（担保金）も少なくて済みます。また、後述するIDVTC（分散型バリデータクラスター）への参加には、ICS取得が前提条件になっています。

> 📎 制度の詳しい解説は、Lido公式ブログの日本語意訳記事（[Daik1氏によるnote記事](https://note.com/buythedipams/n/n7215378a4b5b)）が分かりやすく、本章でも参考にしています。

## 3. 公式スコアリング基準の全容

ICS認証は、3つのカテゴリでのスコアの合計によって判定されます。**合計15点以上、かつ各カテゴリで最低ラインを満たす必要があります。**

### Proof-of-Experience（経験の証明）— 最低5点・最大8点

```
EthStaker solo-stakers list      : 6点
StakeCat solo-stakers list       : 6点
Obol Techne                      : 4〜6点
SSV Verified operators           : 7点
CSM testnet participation        : 4〜5点
CSM mainnet participation        : 6点
SDVTM testnet participation      : 5点
SDVTM mainnet participation      : 7点
```

### Proof-of-Humanity（実在人物の証明）— 最低4点・最大8点

```
Human passport        : 3〜8点
Circles                : 4点
SSV Verified operators : 3点
Discord                : 2点
X                      : 1点
```

### Proof-of-Engagement（コミュニティ参加の証明）— 最低2点・最大7点

```
Aragon Votes参加       : 2点
Snapshot Votes参加     : 1点
Lido Galxeスコア       : 4〜5点
High Signalスコア      : 2〜5点
GitPOAPs               : 2点
```

### 申請フロー

```
① 申請フォームの提出（CSM UI）
② 半自動チェックによるスコア判定
③ 承認された場合、CSM CommitteeがEasy Trackで
   オペレータータイプを付与
④ CSM UIで請求（既存運用者）、または新規作成時に自動付与
```

審査は四半期ごとのラウンド制です。例えば直近のRound #6では、6月8日以降に提出された申請が9月7日に評価される、というスケジュールで運用されています。

## 4. 実際の申請結果（実測データ）

2026年5月29日に申請し、合計17点で承認されました（必要最低ラインの15点を上回る結果）。内訳をそのまま公開します。

### Proof-of-Experience：5点（最低ラインをぎりぎり通過）

```
CSM testnet participation : 5点  ← これのみ
EthStaker / StakeCat / Obol Techne / SSV Verified operators
                           : すべて0点
```

**このカテゴリは、Hoodiテストネットでの継続運用実績（申請時点では第1部・第2部で積み上げてきた、VM検証からベアメタルでの長期運用まで）だけで最低ラインを突破していました。** EthStakerやStakeCatのような外部リストへの登録実績、SSV Verified operatorsの認定は一切なくても、テストネット運用の継続という一点だけで通過できたことになります。

### Proof-of-Humanity：8点（満点）

```
Human passport : 3点
Circles          : 4点
Discord          : 2点
X                : 1点
SSV Verified operators: 0点
```

3〜4項目の合算で満点の8点に達しています。事前にHuman passportやCirclesといった「実在の個人であることを証明する」サービスに登録していたことが、そのままスコアに反映されました。

### Proof-of-Engagement：4点（最低ライン2点を上回る）

```
Lido Galxeスコア: 4点
Aragon Votes / Snapshot Votes / High Signal / GitPOAPs
                : すべて0点
```

こちらはLido Galxeスコアのみで通過しています。逆に言えば、**ガバナンス投票（Aragon・Snapshot）への参加は今回まったく行っておらず、伸びしろとして残っています。**

## 5. ここから見える、実務的な学び

- **テストネットでの継続運用だけで、経験カテゴリの最低ラインは超えられる。** 華々しい外部認定がなくても、地道な運用実績がそのまま評価対象になる。
- **Web3コミュニティでの「身元の可視化」（Human passport・Circles・Discord・X等）を先に済ませておくと、Proof-of-Humanityカテゴリを効率よく満たせる。**
- **ガバナンス投票への参加は、今回は未着手だった。** 今後スコアをさらに積み増したい場合や、次回以降により盤石な形で臨みたい場合に取り組む余地がある。
- **合計17点は、最低ライン15点を辛うじて上回る程度。** 「なんとなく運用していれば自動的に取れる」ものではなく、複数カテゴリでバランスよく実績を積む必要がある。

## 6. 次のステージへ — CSM v3とIDVTC

本章を執筆している2026年7月、CSM自体がv3にアップグレードされました。今回のアップグレードで、IDVTC（Identified DVT Clusters）という新しいオペレータータイプが正式にローンチされています。

```
IDVTC: 4人のICS認証済みオペレーターがクラスターを組み、
       SSVまたはObolでバリデータを共同運用する
Bond : 1.5〜0.5 ETH/鍵（Defaultよりさらに低い）
APR  : 最大7.45%（4タイプ中最高）
参加条件: ICS認証が必須
```

2024年8月、「DVTとは何か」も分からないまま参加したワークショップから約2年。今度は自分自身が、その分散型バリデータクラスターの一員として挑戦する番になりそうです。第3部・第6章で実施した4-of-4クラスターの実地検証は、その意味で既に最初の一歩だったのかもしれません。

パートナー探しという新たな課題はありますが、これもまた、これまでと同じように、焦らず一歩ずつ積み重ねていきたいと思います。
